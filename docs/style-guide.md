# Style Guide — Art, Animation, Camera, Sound (storyboard Parts 1, 5, 8, 9, 10)

## Visual style
Polished Indian Bengali village 2D cartoon: clean vector-style characters, bold smooth outlines, expressive faces, slightly exaggerated proportions, hand-painted-looking layered backgrounds, soft shadows, natural fire/smoke/steam. Avoid: photoreal 3D, redesigns, inconsistent clothing, excessive squash-stretch, size drift, unmotivated camera moves, random background changes.

## Layer order (every scene)
1. Background → 2. environment objects → 3. distant crowd → 4. midground props → 5. main character → 6. foreground props → 7. particles/effects → 8. lighting overlay → 9. dialogue subtitle (preview only) → 10. cinematic overlay.

## Animation rules
- Idle: breathing, irregular blinks, subtle head movement, minimal cloth motion — unique per character.
- Dialogue: mouth synced to Bengali VO (timing master), small nods, eye contact, motivated gestures only, natural pauses. Mouth shapes: rest / open-small / open-wide / round / smile-open / closed-lip.
- Easing: character movement easeInOut; camera easeInOut; object drops spring; facial reactions quick easeOut; steam/smoke continuous slow rise.
- 12 principles apply (squash & stretch through anticipation, staging, follow-through, arcs, secondary action, timing, controlled exaggeration, solid drawing, appeal).

## Cinematography
Extreme wide (establish) / wide / medium (conversation) / MCU (emotional) / CU (reactions) / ECU (handi, food, money, evidence) / OTS (confrontations) / top-down (cooking) / low angle (threats) / tracking (movement). Cuts on gestures; hold close-ups in emotional dialogue; reaction shots after accusations; consistent 180° screen direction.

## Sound map
Dialogue first; never loud music over Bengali dialogue; SFX comfortable and quiet; separate dialogue / narration / music / ambience / SFX tracks; duck music under speech.
Cues: market → cheerful rural; counting money → low thoughtful; greed → subtle suspicious note; fraud prep → darker low bed; Fatik → suspense sting; complaints → subdued; big order → brief celebratory; spoiled reveal → music cuts abruptly; exposure → dramatic low bed; police → serious percussion; loss → sad score; redemption → soft hopeful; moral → warm closing.
